# Sub-processors

As in the [Privacy Policy](https://portal.yousleep.ai/legal/privacy-policy),
section 11. For the data in an organisation's recordings they are youSleep's
sub-processors on the organisation's behalf
([Terms and Conditions](https://portal.yousleep.ai/legal/terms-and-conditions),
section 4.5.7).

| Provider | Purpose | Personal data | Where |
|---|---|---|---|
| Cloudflare | Object storage (R2) for recordings, results and backups; DNS, DDoS protection, secure transport | Stored recordings and results; request metadata such as IP addresses | R2: EU region. Transport: global network |
| SMTP2GO | Transactional email | Recipients' email addresses | See below |
| Google Workspace | The mailbox for contact@yousleep.ai | What is sent to it | See below |
| Stripe | Integrated for possible future payments; not active | None | — |

**Transfers.** Where personal data is processed outside the EEA, youSleep relies
on Standard Contractual Clauses or an adequacy decision (Privacy Policy,
section 12).

**Not sub-processors.** An organisation's own storage and runners. GitHub, which
hosts source code and container images and receives no personal data.

Changes to this list are made in the Privacy Policy, which users are asked to
accept again.
